Pretty paths would be nicer on a projector than `/static/*.html`. If a later pass may edit `app.py`, add HTMLResponse aliases **in addition to** `/` and `/static`:

```python
def _page(name: str) -> HTMLResponse:
    path = STATIC / name
    if not path.exists():
        return HTMLResponse("<h1>missing</h1>", status_code=500)
    return HTMLResponse(path.read_text(encoding="utf-8"))

@app.get("/policies")
def policies_page() -> HTMLResponse:
    return _page("policies.html")
# likewise: /metrics /audit /matrix /architecture /runbook
```

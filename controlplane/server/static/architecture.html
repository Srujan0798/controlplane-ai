An AI response is not text to be scored — it is a set of claims requesting permission to act. Performance, cost and responsibility are three reads of this structure. Click a station.

produces binds authorizes

Three reads

Performance · forward

Does each claim bind to a span?

Not confidence. Assertion strength × groundedness deficit. Default verdict is UNSUPPORTED. A claim must earn SUPPORTED. Not low confidence — unproven.

Cost · backward

Did each step ground an accepted claim?

Any step that grounds zero accepted claims is dead compute — exact, no model. Cost never blocks a user's answer; it kills a runaway loop.

Responsibility · labels

Is the caller entitled, and is the action inside its interlock?

Leakage is set membership + ACL, not a classifier. Bias is counterfactual flip rate, route-level, async. Safety is typed interlocks on the action, not the prose.

Cost · backward

Dead compute

Walk SUPPORTED claims to spans to steps. Any step that grounded nothing is dead compute — counted and named, never estimated. On the refund fixture: faq_search and crm_lookup. Cost never blocks a user's answer; it kills a runaway loop.

Latency · stream

Hold-back

Text streams on a ~150–300 ms trailing delay. Failures inside the buffer never reach the user. The hard gate sits on the action, not the token. Chosen over emit-then-recall: post-hoc retraction has a liability gap by construction.

06Latency is ≤40 ms p50 / ≤200 ms p95. Never quote 40ms as p95 — a five-fold overclaim, dead on contact.
07The FNR report ships as an empty schema with typed placeholders. The emptiness is the credibility play.
08The refuse-to-claim list is about us — not the rejected-approaches list. Do not confuse the two.
09Do not drop bias. Counterfactual flip rate with a confidence interval, route-level, async. Measurement, not morals.

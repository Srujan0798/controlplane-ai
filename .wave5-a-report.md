## Behaviour

### Bias probe (responsibility)

Counterfactual stub over ledger spans vs principal clearance (same ACL ⊆ clearance rule as entitlement):

- `acl_skew` = fraction of spans the principal cannot read
- `flag` = `acl_skew > 0`

Exposed on every gate result:

```json
{
  "responsibility": {
    "bias_probe": { "acl_skew": 0.2, "flag": true }
  }
}
```

Refund fixture: 1 of 5 spans is `hr-confidential` while clearance is `{vendor-public}` → `acl_skew=0.2`, `flag=true`. Not a per-response moral verdict — measurement surface only.

### Prometheus

`GET /prometheus` returns Prometheus text exposition (plain text), separate from HTML `GET /metrics`:

| Metric | Type | Source |
|---|---|---|
| `controlplane_decisions_total` | counter | `ShadowCounters.total_decisions` |
| `controlplane_would_hold_total` | counter | `ShadowCounters.would_have_held` |
| `controlplane_gate_latency_ms` | gauge | last gate `latency_ms` via `MetricsStore.record_latency` |

JSON snapshot at `GET /v1/controlplane/metrics` also includes `gate_latency_ms` / mean / count.

### Makefile `judge`

Prints autorun deep-link, Prometheus curl tip, and gate latency p50/p95 from `submission/latency_bench.json` (currently **p50=0.05 ms**, **p95=0.167 ms**).

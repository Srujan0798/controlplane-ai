## Behaviour

### SessionStore

- `begin_session(session_id, principal_id)` — idempotent
- `attach_request(session_id, request_id, summary)` — parent chain (`parent_request_id` of turn n is turn n−1)
- `compounding_risk(session_id)` → `{request_count, prior_holds, prior_escalations, compounded}`
- `compounded: true` iff any attached summary has an **Escalate** actuator
- Optional sqlite tables `sessions` / `session_requests` on the same DB path as `AuditStore`

### HoldBackBuffer

- Default `delay_ms=200`; records `intended_release_at` — **does not sleep** (Lane 1)
- `admit(text, ok) → {released, held, delay_ms}`
- `ok=False` → never released
- Actuator Edit / Escalate / Block → `held=True` (irreversible path)

### HTTP

- `POST /v1/controlplane/sessions` `{session_id, principal_id?}`
- `GET /v1/controlplane/sessions/{session_id}` (404 if missing)
- `POST /v1/controlplane/demo/{scenario}?session_id=` attaches the gate result and returns `compounding_risk`
- Gate `response_overlay.holdback` present on refund (pipeline) and support/copilot (`_wrap_multi`)

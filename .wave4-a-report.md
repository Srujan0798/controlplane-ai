## Behaviour

### Chat / completions

1. If `scenario` is present (body, `X-ControlPlane-Scenario`, or keyword inference) → **demo path** (refund enforce still Edit + Escalate).
2. Else if `CONTROLPLANE_UPSTREAM_URL` is set (or `create_app(enable_upstream=True)`) → `forward_chat`, then attach:

```json
{
  "upstream": true,
  "demo_fixtures_used": false,
  "note": "Upstream passthrough. Lane-1 demo fixtures were not used. Edit/Escalate/Block are not applied without provenance."
}
```

No fake actuators. Missing URL → `UpstreamNotConfigured` → HTTP 501. Transport failure → 502. No scenario and no upstream → 400.

Keyword inference no longer silently defaults to `refund`, so a real model call is reachable. Messages containing refund / clause 7.2 still take the demo path.

### Webhook

After demo or chat **enforce** results whose decisions include **Escalate** or **Block**, `notify_escalate` POSTs the public dict to `CONTROLPLANE_WEBHOOK_URL` (timeout 2s). Shadow mode does not fire. Failures are logged and swallowed.

### Signed audits

- `GET /v1/controlplane/requests/{id}/audit.jsonl` includes `X-ControlPlane-Signature` (hex HMAC-SHA256 of the JSONL bytes).
- `GET /v1/controlplane/requests/{id}/audit.jsonl.sig` returns the same hex.
- `POST /v1/controlplane/audit/verify` body `{content, signature}` → `{valid: bool}`.

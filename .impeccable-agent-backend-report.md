## Behaviour

### Persist

- Path: `CONTROLPLANE_DB` or default `.data/controlplane.db`
- `save(public_dict)` / `list(limit, offset)` / `get(request_id)` / `count()` / `ok()`
- Single connection, `check_same_thread=False`, `threading.Lock`, WAL
- Demo + chat gate results persist after `public_dict()`; persist failures never fail the gate
- `GET /v1/controlplane/requests` and `GET .../requests/{id}` prefer SQLite when rows exist, else in-memory `gate.history` / `gate.get`
- `GET /v1/controlplane/ledger/{id}/verify` → `{request_id, chain_valid}` from the stored payload

### Security

- If `CONTROLPLANE_API_KEY` is set, `/v1/*` requires `X-API-Key` or `Authorization: Bearer`. `/healthz` and `GET /` stay open (judge console + probes).
- In-memory sliding 60s window per IP; `CONTROLPLANE_RPM` default 120; `rpm<=0` disables
- Headers on every response (and on 401/413/429): CSP (`'self'` + `fonts.googleapis.com` / `fonts.gstatic.com`, inline CSS/JS for the static console), `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `X-Frame-Options: DENY`
- `MAX_BODY_SIZE = 1_000_000` via `Content-Length` → 413

### Health

`GET /healthz` now includes `db_ok` and `policies_count`. `ok` remains True when the process is up (gate stays available if SQLite is down).

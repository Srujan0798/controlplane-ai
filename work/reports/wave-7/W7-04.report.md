# W7-04 — Fail-stance by blast tier (PARTIAL #12)

## Goal
Enforce a policy pack's declared fail-stance at the Action Interlock so that a
closed stance flips matrix Pass verdicts toward Escalate at irreversible blast
tiers (R2/R3). PARTIAL #12 closure: no new Pass-without-proof path.

## Files changed

### `controlplane/interlock.py`
- `controlplane/interlock.py:72` — new helper `_is_fail_closed(stance)`:
  returns True for `"closed"` and the pack vocabulary `"closed_escalate"`
  (prefix match), False for `"open_annotate"`.
- `controlplane/interlock.py:85` — `decide()` gains `fail_stance: str = "closed"`
  (caller-omitted stance fails closed).
- `controlplane/interlock.py:181` — enforcement block, inserted **after** the
  MATRIX lookup and **before** `Decision(...)` construction. Monotonic: only
  downgrades a pass-level verdict; never relaxes a stricter one.

### `controlplane/policy.py`
- `controlplane/policy.py:112` — `_parse_pack` default `fail_stance` changed from
  `"open_annotate"` to `"closed"` (fail closed when a pack omits the field).

### `controlplane/pipeline.py`
- `controlplane/pipeline.py:151` — `decide(...)` now receives
  `fail_stance=pack.fail_stance` so the live gate enforces the pack's stance.

### `tests/test_interlock.py`
- `test_supported_not_violated_is_pass` split into `..._open_stance` (still Pass)
  and `test_supported_but_closed_stance_escalates_at_r3` (now Escalate). The
  task explicitly inverts the R3-supported→Pass behavior for closed stances.

### `tests/test_fail_stance_tier.py` (new)
- Requirement 1: closed + R3 + supported claim → Escalate.
- Requirement 2: closed + R3 + one UNSUPPORTED driving claim → Escalate (held).
- Requirement 3: default (closed) + R2 + supported claim → Escalate.
- Requirement 4: R0/R1 + supported + closed → may still Pass.
- Guards: open stance never flips; closed-family vocabulary (`closed`,
  `closed_escalate`) both escalate.

## Exact enforcement rule
```
if _is_fail_closed(fail_stance) and actuator in {PASS, PASS_ANNOTATE}:
    if action.tier in {R2, R3}:
        actuator = ESCALATE
        packet["fail_stance_enforced"] = True
```
- R3 (irreversible payment): forced Escalate even with a fully supported claim.
- R2 (irreversible blast): any pass-level verdict → Escalate.
- R0/R1 (low blast): untouched — may still Pass.
- MATRIX unchanged (transcribed, never redrawn); no new actuator.
- Only downgrades, never relaxes — fails closed toward Escalate.
- Refund path uses held vocabulary: `execute_refund(allowed=False)` →
  `{"committed": False, "status": "REFUND HELD"}`.

# W7-01 — CORS allowlist

## What was done

Configurable CORS allowlist driven by `CONTROLPLANE_CORS_ORIGINS` (comma-separated). Unset → judge-port defaults; empty → deny all cross-origin (fail closed).

## Files changed
- `controlplane/security.py` — added `DEFAULT_CORS_ORIGINS` (judge ports 8787/8080 on 127.0.0.1+localhost) and `cors_origins_from_env()` (parses env; unset→defaults, empty→`[]`).
- `controlplane/server/app.py` — import `CORSMiddleware` + `cors_origins_from_env`; `app.add_middleware(CORSMiddleware, allow_origins=cors_origins_from_env(), allow_methods=[GET,POST,OPTIONS], allow_headers=[Content-Type, X-API-Key, Authorization], max_age=600)`.
- `tests/test_cors.py` (new) — defaults cover judge ports; empty env denies all; allowed origin preflight returns ACAO; disallowed origin gets no ACAO header.
- `.env.example` already carried `CONTROLPLANE_CORS_ORIGINS` (unchanged).

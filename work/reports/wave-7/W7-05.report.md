# W7-05 — Graceful shutdown

## What was done

FastAPI `lifespan` context closes SQLite handles (AuditStore + SessionStore) on SIGTERM so WAL flushes and no connection survives shutdown.

## Files changed
- `controlplane/server/app.py` — `@asynccontextmanager async def lifespan(app)`; `FastAPI(..., lifespan=lifespan)`; on shutdown iterates `(store, sessions)` and calls `close()` if present (lock-guarded no-op when unopened).
- `tests/test_lifespan.py` (new) — with `TestClient(app)` as context: healthz 200, store OK during life; after exit `store.count()` raises `sqlite3.ProgrammingError` (closed) and `sessions._conn is None`; unopened store path is a safe no-op; plain (non-context) `TestClient(create_app())` still works.

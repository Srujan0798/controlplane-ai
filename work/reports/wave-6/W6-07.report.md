## How to Install & Run E2E Tests

### Install Playwright
```bash
# From project root
pip install -e ".[e2e]"

# Install browser binaries (Chromium required)
playwright install chromium
```

### Run All Tests Including E2E
```bash
pytest -q
# Both playwright tests now run (no skip)
```

### Run Only Playwright Tests
```bash
pytest -k playwright -v
```

### Notes on Browser Installation
- **Chromium binary ~200–400 MB** — downloaded via `playwright install`
- **First install takes ~1–2 min** for binary download and cache
- **Cached after first install** — subsequent runs are fast
- **CI/CD friendly**: CI jobs skip gracefully; users can opt-in with `.[e2e]`

## Test Structure
- Separate ports (18787, 18788) for each e2e test to avoid race conditions
- Each test manages its own uvicorn server thread lifecycle
- Proper cleanup with `server.should_exit` and `thread.join(timeout=5)`
- Timeout handles slow browser launches gracefully

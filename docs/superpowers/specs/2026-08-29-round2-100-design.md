The repo is **submittable today**. Nothing in this plan may make that false.

- **Every phase ends green and submittable.** If the week evaporates at any point,
  `git checkout v0.2.0-round2` remains a valid submission.

## 3. Architecture of the change

```
                        ┌─────────────── NEW ───────────────┐
response text ──▶ extract.py ──▶ claims[] ──┐
                                            │
context assembly ──▶ recorder.py ──▶ spans[]┤
                                            ▼
                          ┌─────────── binder.py (REWRITE) ──────────┐
                          │  numeric.py  → recompute + normalize     │
                          │  symbols.py  → clause/ID symbol table    │
                          │  bm25.py     → lexical retrieval + gate  │
                          │  derived     → recompute or UNKNOWN      │
                          └──────────────────┬───────────────────────┘
                                             │  bindings[] (+ rationale)
                       pii.py (NEW) ─────────┤
                                             ▼
                    entitlement.py ──▶ findings[] ──▶ interlock.py (UNCHANGED)
                                             │
                    lanes.py (NEW) ──────────┤ deadlines → UNKNOWN on miss
                                             ▼
                                        decisions[]
                                             │
              economist.py (NEW) ────────────┤ dead compute
              feedback.py  (NEW) ────────────┤ overrides → labels → thresholds
              bias.py      (REWRITE) ────────┘ counterfactual flip rate + CI
```

**`interlock.py` and `models.py` (the `Actuator`/`BlastTier` enums and the MATRIX) are
frozen and unchanged.** Everything new feeds the interlock; the interlock stays sole decider.
This is the invariant that keeps the architecture's central claim true.

## 4. Phase plan

Nine phases. Each has an exit gate that must be green before the next starts.

### Phase 0 — Content laws as CI (½ day)

Turn `ARCHITECTURE.md` §10's nine laws into `tests/test_content_laws.py`, asserting across
**code, docs, the built PDF's extracted text, and the deck's extracted text**:

1. `clause 7.2` never appears adjacent to *caps / denies / covers / limits* — only *absence*.
2. The word `blocked` never appears in refund language in any artifact.
3. `MATRIX` equals the 16 transcribed cells exactly (byte-comparison against a literal).
4. `Actuator` has exactly five members; no invented actuator name (`STREAM`, `Kill Span`,
   `Terminate Step`, `Hold & Re-verify`, `Redact & Flag`) appears in any artifact.
5. `40ms` never appears within N characters of `p95`.
6. The gate report schema carries typed placeholders, never fabricated numbers.
7. A refuse-to-claim list exists and is textually distinct from the rejected-approaches list.
8. A bias section exists in the proposal and the deck.
9. The company pays ₹1,84,000; the customer does not lose money.

**Exit gate:** `pytest tests/test_content_laws.py` green on the current tree, before any
behavior changes. From here, drift fails CI.

### Phase 1 — Claim extraction (1 day)

**New: `controlplane/extract.py`.** Arbitrary text → typed claims. Pure Python, zero deps,
offline, sub-millisecond. No LLM — this is Lane 1.

- **Segmentation** that survives `₹1,84,000.`, `Clause 7.2`, `§4.1`, `Dr.`, `e.g.`, decimals.
- **Check-worthiness filter** — the architecture names this as the largest FP-reduction lever.
  Drop greetings, meta-statements, pure questions, contentless hedges. Keep sentences carrying
  a quantity, entity, date, document/clause/ID reference, causal connective, or policy modal.
- **Typing**, with strict precedence `DERIVED > NUMERIC > TEMPORAL > STRUCTURAL > TEXTUAL`.
  Derived must never be mistyped as directly checkable — that is the §7 false-assurance boundary.
- **Assertion strength** from a hedge lexicon with negation scoping (`may`, `might`, `typically`,
  `approximately`, `appears`, `should`, `I believe`, `around`, `likely`).
- **`role_in_action` computed, not typed** — a claim's weight for an action derives from overlap
  between the claim's entities/quantities and the action's arguments, plus locality to the
  action-triggering sentence.

**Optional adapter (behind `CONTROLPLANE_EXTRACTOR=llm`):** identical interface, small-model
extraction. Shown as the generalization answer; the demo never depends on it.

**Exit gate:** extraction over the refund response text alone produces the six claims with
correct kinds and assertion strengths. No `Claim(...)` literal remains in the demo path.

### Phase 2 — Binder v2, four real routes (1.5 days)

**Rewrite `controlplane/binder.py`; interface unchanged.** New helpers `numeric.py`,
`symbols.py`, `bm25.py`.

| Route | Mechanism | Verdicts reachable |
|---|---|---|
| **NUMERIC** | Normalize both sides (currency symbols, Indian *and* Western digit grouping, `lakh`/`crore`/`k`/`M`, percentages, units) then match against quantities extracted from spans, with per-unit tolerance. | SUPPORTED · **CONTRADICTED** · UNSUPPORTED |
| **STRUCTURAL** | Symbol table built at context-assembly time: every clause/section/ID/entity token in every span → span_ids. Claim references are looked up. | SUPPORTED · UNSUPPORTED |
| **TEXTUAL** | Pure-Python BM25 over the **provenance set only**, top-k, then a lexical-entailment gate (content-word coverage + negation/antonym detection). Three bands. | SUPPORTED · **UNKNOWN** · UNSUPPORTED · CONTRADICTED (on negation) |
| **DERIVED** | Attempt recomputation from span quantities (sum/avg/count/diff). Not recomputable → **UNKNOWN**, never SUPPORTED. | SUPPORTED · CONTRADICTED · **UNKNOWN** |

This closes F1, F2 and F3 together: numeric contradiction makes `Block` live, the TEXTUAL
middle band and DERIVED make `Unknown` live, and the amount claim binds **for real**.

Two demo consequences worth naming:

- Clause 7.2 now fails **organically and showably** — the console can print the symbol table
  ("the provenance set contains 4.1, 4.3, 9.1 — 7.2 is not among them"). Strictly stronger
  than the current beat, because the judge sees the mechanism rather than the outcome.
- Every binding carries `method` **and `rationale`**, so the evidence packet explains *why*.

**Fixture removal:** `run_prepared` rejects `fixture_map` when `mode == "enforce"` unless an
explicit `allow_fixtures=True` is passed (tests only). A test asserts the refund demo runs with
`fixture_map=None`.

**Exit gate:** refund demo reproduces Edit + Escalate(held) with zero fixtures; all 16 matrix
cells have at least one reaching test; `grep fixture` over the demo path is empty.

### Phase 3 — Leakage: PII and entity binding (½ day)

**New: `controlplane/pii.py`.** Aho-Corasick automaton (pure Python) over a gazetteer built
from spans plus a static sensitive-token set, and checksum-validated detectors: PAN, Aadhaar
(Verhoeff), email, Indian phone, IFSC, card (Luhn), IBAN.

- **Rule A (missing today):** a PII-shaped entity in the output binding to **no** span is a
  model-memory leak or fabrication → forces the `Contradicted` column → Block at R2/R3.
- **Rule B (exists):** an entity binding to a span whose ACL excludes the principal → the
  existing entitlement path.

Also fixes **F7**: `multi_usecase.py` gets genuinely mixed-ACL span sets so violations can fire.

Rule A is the PDF's "a fabricated detail about a person is simultaneously a hallucination and
a privacy concern" — answered by one mechanism rather than two classifiers.

**Exit gate:** a fabricated PAN in a response yields Block at R3; a real PAN from an entitled
span passes; a real PAN from an unentitled span yields the entitlement path. Three tests.

### Phase 4 — The numbers (1.5 days)

**4a. Eval corpus + harness (`evals/`).** 150–200 YAML cases:
`{response_text, spans[], principal, actions[], expected_verdicts, expected_actuators, label}`.

Strata: three PDF use cases × {clean, hallucinated-numeric, hallucinated-structural,
unentitled-span, PII-leak, derived-trap, hedged-borderline, multi-turn-inherited,
prompt-injection}. **Deliberate hard negatives included** — cases that look wrong but are
correct. Without them the FP number means nothing.

`make eval` prints, per route: precision, recall, **FPR and FNR each with a Wilson score
confidence interval**, the confusion matrix, and the abstention (UNKNOWN) rate.

This converts ARCHITECTURE §7's claim shape from a placeholder into printed output:
> *"On this route we catch X% of ungrounded claims at Y ms p50 — and here is the Z% we don't."*

**4b. Dead compute (`controlplane/economist.py`).** Exact backward walk: accepted claims →
bindings → spans → steps; steps grounding zero accepted claims are dead. Report count, token
estimate, ₹ at a stated rate, and ₹ per 1k requests. Plus near-duplicate tool calls (arg hash),
retry loops, and re-retrieval of spans already in context.

**4c. Bench at claimed scale (`scripts/load_bench.py` v2).** 10,000 requests, concurrency
sweep, per-stage breakdown (extract / bind / entitle / interlock), p50/p95/p99, sustained
throughput mapped to "tens of thousands per week". Emits a `methodology` block so the number
is not quotable out of context.

**Exit gate:** `make eval` and `make bench` both print real numbers; those numbers are the
only ones any artifact quotes.

### Phase 5 — Lanes, for real (1 day)

**New: `controlplane/lanes.py`.** `asyncio.gather` with per-lane deadlines. Lane 1 hard
30–60 ms, deterministic only. Lane 2 near-line (the NLI adapter slot). Lane 3 async
(bias replay, calibration, shadow replay). **Deadline miss returns UNKNOWN, resolved by that
tier's fail stance** — never by a global default.

Proof test: inject an artificially slow Lane 2, assert the decision still lands inside budget
via UNKNOWN, and assert a slow probabilistic check never overturns a fast deterministic one.

**Exit gate:** the deadline test passes; the bench shows Lane 1 p95 inside its declared budget.

### Phase 6 — Governance, feedback, bias (1.5 days)

**6a. Jurisdiction axis (F12).** Packs gain `jurisdiction`, `regulatory_basis`
(EU AI Act Art. 14 · DPDP Act 2023 · GDPR Art. 22), `retention_days`, and `tier_overrides`.
It must **change behavior**: a test proves the same request under an `eu` pack and an `in`
pack yields different actuators. Answers the PDF's "geography" clause directly.

**6b. Feedback loop (F10).** `POST /v1/controlplane/decisions/{id}/override` → reviewer,
verdict, reason, written **into the chained ledger** so overrides are tamper-evident too.
Overrides become labels feeding the eval corpus. Threshold proposals run a **shadow replay over
the last N traces and print the FP/FN delta before shipping** (ARCHITECTURE §4). Canary with
auto-rollback when override rate exceeds 3× baseline — a state machine with tests.

**6c. Bias v2 (F9).** Replace the ACL fraction with counterfactual replay: perturb protected
attributes on decision-shaped routes, measure **decision-flip rate with a Wilson CI over a
rolling window**, flag when the CI excludes zero. Async/Lane-3, per-route never per-response,
framed in measurement terms (content law #9).

**Exit gate:** jurisdiction test proves divergent actuators; an override changes a threshold
only after a printed shadow-replay delta; bias reports a flip rate with a CI.

### Phase 7 — Multi-turn compounding risk (½ day)

The PDF names it; no other team will demo it.

Turn 1: a hedged claim passes at R1 (`Pass + annotate`). Turn 3: an R3 action's
`role_in_action` **inherits that turn-1 claim**. The gate re-evaluates the inherited claim at
R3 severity → Escalate. One questionable output shaped a downstream decision, and the plane
caught it at the commit path.

**Exit gate:** scenario runs end-to-end; a test asserts the turn-1 verdict is unchanged and the
turn-3 actuator escalates because of it.

### Phase 8 — The room (1.5 days)

**8a. The screen that ends it.** One console page: paste any response text, edit the span set,
pick a principal, pick an action → live graph, extracted claims with types and hedging, binding
method **and rationale**, the symbol table, the matrix cell, the actuator, the evidence packet,
dead compute, and the per-stage latency breakdown. This is the answer to *"run it on my text."*

**8b. Rebuild `submission/ControlPlane_Round2_Proposal.pdf` and `.pptx`** against real numbers,
with an eval table and the published FNR.

**8c. Hostile Q&A v2** — the new capabilities invite roughly twelve new attacks
(*"your BM25 threshold is a magic number"*, *"Wilson CI on 150 cases is wide"*,
*"your corpus is self-authored"*). Each gets a drilled answer.

### Phase 9 — Verification (½ day)

**`make verify`** — one command: preflight → tests → content laws → eval → bench → then
**diff every number printed against every number quoted in the PDF and deck.** Any drift fails.

Then: `security-review`, `code-review` at high effort, and a determinism check asserting the
same input yields a byte-identical ledger hash across runs and across processes.

**Exit gate:** `make verify` green; `docs/ACCEPTANCE.md` regenerated with the new SHA and real
outputs; every claim in every artifact traceable to one command.

## 8. Risks

| Risk | Mitigation |
|---|---|
| Rewriting the binder breaks the demo before the room | Branch + intact tag; every phase exits green and submittable |
| A real binder makes the refund beat weaker than the fixture did | Phase 2 exit gate requires Edit + Escalate(held) reproduced with zero fixtures, or the phase does not close |
| BM25 thresholds read as magic numbers — the exact thing ARCHITECTURE §8 rejects | Thresholds are **calibrated on the eval corpus and published with their FP/FN curve**, never asserted. This is why Phase 4 must not slip before Phase 2 ships thresholds |
| Self-authored eval corpus is circular | State it plainly; include hard negatives; publish the corpus alongside the numbers so a judge can attack it |
| Scope creep reopens the frozen architecture | `ARCHITECTURE.md` is read-only for this work; anything that seems to need a change stops and asks |
| A week is not a year | Phases are ordered by score-per-hour. Stopping after Phase 4 still lands ~90 |
